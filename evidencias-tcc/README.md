# Evidências acadêmicas do TCC

Esta pasta separa os materiais de análise dos arquivos de implementação.

- `01-resultados-k6/`: campanhas aprovadas e cinco rodadas oficiais por endpoint e implementação.
- `02-auditoria-sql/`: consultas Raw SQL, SQL capturado de TypeORM e Prisma, e o experimento N+1.
- `arquivos-para-envio/`: versões ZIP enxutas para compartilhamento.

Os resultados de benchmark incluídos correspondem exclusivamente ao perfil `baseline`, com 50 VUs, warm-up de 1 minuto e cinco rodadas de 3 minutos.
